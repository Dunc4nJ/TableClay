# Claude Code Skills Guide for Table Clay

## How to Install Skills

Skills extend Claude's capabilities through organized folders containing instructions and resources.

### Installation Methods

#### 1. Personal Skills (Available across all projects)
```bash
# Create personal skill directory
mkdir -p ~/.claude/skills/skill-name

# Add SKILL.md file with content
```
Location: `~/.claude/skills/`

#### 2. Project Skills (Shared with team via git)
```bash
# Create project skill directory
mkdir -p .claude/skills/skill-name

# Commit to git
git add .claude/skills/
git commit -m "Add skill"
```
Location: `.claude/skills/` within your project

#### 3. Plugin Skills
Skills bundled with Claude Code plugins - automatically available when plugin is installed.

---

## SKILL.md File Format

```yaml
---
name: your-skill-name
description: Brief description of what this Skill does and when to use it
allowed-tools: Read, Grep, Glob  # Optional: restrict available tools
---

# Your Skill Name

## Instructions
Provide clear, step-by-step guidance for Claude.

## Examples
Show concrete examples of using this Skill.
```

**Field Requirements:**
- `name`: lowercase letters, numbers, hyphens only (max 64 chars)
- `description`: Brief description including when to use it (max 1024 chars)

## Skill Evaluation: shadcn-ui-best-practices

**URL:** https://claude-plugins.dev/skills/@JewelsHovan/pain-plus-site/shadcn-ui-best-practices

### Overview
- **Author:** @JewelsHovan/pain-plus-site
- **Stars:** 0 | **Downloads:** 3
- **Description:** Guide for proper shadcn-ui component usage - use Card for wrapping/layout, compose from base components, never modify components/ui directly

### Key Principles
1. **Never Modify `components/ui/` Directly** - Base primitives generated by shadcn-ui CLI should not be edited
2. **Compose in `components/shared/`** - Create custom components that use the base primitives
3. **Card Component Usage** - Use Cards for wrapping/layout, grouping content, creating sections

### Directory Structure Recommended
```
src/
├── components/
│   ├── ui/           # Base shadcn primitives (DO NOT MODIFY)
│   │   ├── button.tsx
│   │   ├── card.tsx
│   │   └── ...
│   └── shared/       # Your composed app components (CREATE HERE)
│       ├── FeatureCard.tsx
│       └── StatCard.tsx
├── pages/            # Page components (USE ui components here)
└── lib/
    └── utils.ts      # cn() utility for className merging
```

### Verdict: MODERATELY USEFUL

**Pros:**
- Enforces good separation of concerns
- Prevents breaking changes when updating shadcn-ui
- Promotes component composition pattern

**Cons:**
- Very low adoption (only 3 downloads)
- Specific to Vite + React (we use Next.js)
- Our project already has its own component structure in `modules/`

**Recommendation:**
The principles are sound but **not essential** for Table Clay. Our storefront uses Medusa's module-based architecture (`src/modules/`) which already provides good separation. The official **shadcn-ui** skill (428 stars) would be more broadly useful.

## Quick Install Commands

```bash
# For Claude Code CLI installation of skills from the marketplace:
# 1. Download the skill ZIP from the marketplace
# 2. Extract to ~/.claude/skills/ or .claude/skills/

# Example: Create a custom Table Clay skill
mkdir -p .claude/skills/table-clay-conventions
cat > .claude/skills/table-clay-conventions/SKILL.md << 'EOF'
---
name: table-clay-conventions
description: Table Clay project conventions for Medusa.js e-commerce with Next.js storefront. Use when working on the Table Clay pottery e-commerce project.
---

# Table Clay Development Conventions

## Project Structure
- Backend: `table-clay-store/` (Medusa.js 2.12.3)
- Frontend: `table-clay-storefront/` (Next.js 15.3.8)

## Key Directories
- Components: `storefront/src/modules/`
- Styling: Tailwind CSS in `tailwind.config.js`
- API Routes: `table-clay-store/src/api/`

## Conventions
- Use App Router (Next.js 15)
- Prefer server components where possible
- Follow Medusa module patterns for backend extensions
EOF

echo "Skill created at .claude/skills/table-clay-conventions/"
```
